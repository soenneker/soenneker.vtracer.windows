# ![](https://user-images.githubusercontent.com/4441470/224455560-91ed3ee7-f510-4041-a8d2-3fc093025112.png) Soenneker.Vtracer.Windows
### A bundled VTracer command-line distribution for Windows x64.

## Installation

```
dotnet add package Soenneker.Vtracer.Windows
```

The file is copied to the output directory, and located at the relative path: `Resources\`.
